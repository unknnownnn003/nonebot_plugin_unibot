# nonebot-plugin-unibot

基于 NoneBot2 的 CHUNITHM (中二节奏) 查分、曲库、剧情与图片生成插件。歌曲、谱面和定数统一使用落雪 (Lxns) 国服曲库；旧成绩上传和同步方式在第三阶段替换前继续兼容。

## 任务控制

补发本身也是独立FIFO任务，原生成任务与补发任务ID分开，返回新ID后可用 `/中二任务` 查询或 `/取消中二任务` 停止后续发送。已开始的投递可能完成，历史未知不会因取消变成“未发送”。补发不再查分、渲染、消耗猜曲提示或记分。原生猜曲仍即时执行原游戏状态机，投递另外记录到缓存；成功时原文字/图片格式不变，失败可按媒体任务ID补发，游戏操作不会重跑。

原命令及附件交互的每一步会在执行前写入本插件 localstore 的 `native_commands.sqlite3`。同一 Bot、会话、发起者和真实消息重复投递时不再执行同一步；消息已由原命令接管时，Agent 也不会再次执行。回执表示接管，不能据此认定业务成功；结果不明时查询原任务或记录。原权限、命令解析和上传等待流程保持，正常新消息仍可继续附件交互。

成绩同步、资源维护和剧情生成使用本插件持有的 SQLite/FIFO 队列，不依赖 llmchat。`/中二任务 [任务ID]` 查询当前 Bot、当前群聊或私聊中自己的最近任务或指定任务；`/取消中二任务 <任务ID>` 请求取消自己的任务。执行中只表示已请求取消，已完成的写入不会回滚，最终结果以任务状态为准。

B/B30、个人信息、OP进度、推荐、歌曲详情/候选图和帮助图也共用该队列与原渲染器。原命令接单返回任务ID，生成的原图可由 `/补发中二任务` 只补缓存；不会重新查分、推荐或迁移成绩。原B30命令仍执行旧手动分数迁移，Agent B30仍保持只读。查歌候选先按真实会话/发起者绑定，再异步生成候选图，重复消息读取同一任务快照；候选图发送完成是成功任务，等待选择另行标明。

`/查剧情`、`/随机剧情` 返回任务 ID，生成后仍发送原图片与合并转发；合并转发失败时保留前两张图片的降级限制。生成结果在发送前保存到数据目录的 `native_presentations.sqlite3` 和同名 `_files` 目录。`/补发中二任务 <任务ID>` 只补发当前会话中本人任务未确认送达的缓存，不重新渲染、下载或随机选择。任务执行状态与媒体补发状态分别保留；同一条真实补发消息仅尝试一次，需要再次尝试时请发送新请求。`/chuhelp` 列有三个任务入口。重启不会伪造旧请求继续生成，已生成的完整投递计划仍可补发。

## 数据源说明

- 歌曲和谱面只使用落雪国服数据。旧混合曲库按来源在内存中过滤；下次 `/更新songlist` 写入统一结构前会完整备份旧文件，不删除旧成绩、绑定、别名或曲绘。
- ULTIMA 保留自身谱面版本；WORLD'S END 保留独立歌曲 ID、`origin_id`、属性、星级和版本。查询原曲时可合并展示明确关联的 WORLD'S END，不按同名合并其他歌曲；独立 ID 查询仍可用。
- `/b30` 仍读取国服和手动成绩取最高分，但改用国服定数。无法匹配国服谱面的历史记录保留在磁盘，结构化结果提供未匹配数量；全部无法匹配时返回明确说明。
- Rin JSON、CSV 导入与本地玩家资料回退仅作为第三阶段前的旧成绩兼容，不参与曲库、歌曲 ID 或定数补全；原落雪开发者密钥同步暂不变。
- 已移除日服曲库更新、上传和抓取工具。旧缓存工具调用、历史维护任务和综合面板的旧日服选项返回 `SOURCE_RETIRED`，提示改用 `/更新songlist`，不会发起外源请求或伪报成功。

## 帮助与交互维护

`/chuhelp`（别名 `/中二帮助`）显示帮助图；`/chuhelp 文字` 返回完整文字，`/chuhelp 成绩`、`/chuhelp 曲库`、`/chuhelp 猜曲`、`/chuhelp 剧情`、`/chuhelp 维护`、`/chuhelp 任务` 按分类查看。

同时加载综合功能插件时，超级用户可在宿主配置的 `LOG_GROUP_ID` 日志群发送 `/设置面板`，按编号批量提交 UniBot 资源维护。维护仍走原任务队列，在日志群使用 `/中二任务` 查询。曲库、曲绘、收藏品和剧情是全局资源，保存前会明确预览；凭据仍由宿主配置管理。


## 2026-11-15 统一群策略

- 三插件共享综合插件 feature_config.json 的 _policy_version=2，按群保存 _plugins 总开关及单项选择；新群和新功能默认关闭。
- 原 _whitelist、绘图白名单及环境默认白名单不再强制开启任何功能。关闭总开关保留单项、LLM预设和概率。
- 现有运行环境必须先以已加入群和旧实际状态迁移，再加载新版本；不得在导入期猜测UniBot/LLM启用状态并覆写旧文件。
- 原命令、工具目录与执行、后台任务、延迟通知及Bot出站API均遵守当前群策略；管理设置及本人任务查询/取消保持原权限可用。关闭期间不新增群聊上下文。
- 群设置不改变私聊、SUPERUSER/群角色、绘图审核、额度、预算、账本与幂等规则。
