# nonebot-plugin-unibot

基于 NoneBot2 的 CHUNITHM (中二节奏) 查分与数据统计插件，主要接入落雪 (Lxns) 查分器 API，提供完善的成绩归档、进度查询与排版出图功能。


## 指令列表

| 指令 | 权限 | 描述 |
| --- | --- | --- |
| `/bind <好友码>` | USER | 绑定你的落雪查分器好友码，以便拉取云端数据（若QQ号已绑定lxns则可跳过该步骤） |        
| `/chuupdate` | USER | 上传 lxns 导出的分数 CSV 或 rin 导出的 JSON，并更新本地成绩归档 |    
| `/个人信息` | USER | 查询并生成玩家的落雪 (Lxns) 游玩个人数据图片（别名：`/分数`、`/chuinfo`） |
| `/chulist <查询条件> [--nocat]` | USER | 按难度、定数、版本或特定分类生成对应的 Overpower 进度及评价统计图，支持多个条件叠加取交集。 |
| `[曲名或ID]是什么歌` | USER | 根据曲名、别名、拼音、罗马音等模糊查询并生成精美歌曲详情图（无前缀触发，例如：`1066是什么歌`） |
| `/添加别名 <ID> <别名>` | USER | 为指定ID曲目添加本地检索别名 |
| `/删除别名 <ID> <别名>` | SUPERUSER | 删除指定曲目的本地别名 |
| `/查看别名 <模糊搜索/名字/ID/别名>` | USER | 获取目标歌曲现有的本地及官方别名 |
| `/chuhelp` | USER | 查看本插件内的基本使用指令帮助菜单 |
| `/更新songlist` | SUPERUSER | 更新本地 `songlist.json` 曲库数据（更新时不会抹除用户添加的别名） |
| `/更新曲绘` | SUPERUSER | 获取并更新全部曲绘到 `data/jacket/` 目录 |
| `/查剧情 <角色名/关键词>` | USER | 搜索并阅读指定角色的剧情 |
| `/随机剧情` | USER | 随机抽选一段角色剧情阅读 |
| `/剧情列表` | USER | 查看当前已收录剧情的所有角色列表 |
