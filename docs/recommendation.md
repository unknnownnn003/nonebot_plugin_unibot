# 推荐算法与离线预览

`推什么` 默认从推分、推 OP 和综合三个方向各选一首。指定一种方向时最多给出三首。等级使用落雪显示字段，`14+` 和 `14` 都是显示等级，`14.8` 是精确定数。连击模式查找尚未达成的 FC、AJ 或 AJC；等级与方向可以交换顺序。当前曲库、OAuth 快照、原请求作用域和群开关与其他个人查询共用。

## 候选与排序

- 先按原始歌曲 ID 和谱面难度关联成绩。候选来自已配信、未禁用、有定数的普通谱面，覆盖 BASIC 至 ULTIMA。按原始歌曲 ID 去重，保留同名不同 ID。无符合条件的谱面时返回明确提示。
- 对候选查看 ±0.75 定数内最多八首其他歌的实绩，同一首邻近歌曲只算一次，按定数距离优先。以邻近最高分的中位数辅助判断目标，以样本数和距离调节置信度。落雪无成绩记录的谱面须有至少三首近邻，并使用已观察到的评级线作为首个目标。
- 已有记录时从本谱最高分寻找下一条评级线。跨距较大时给出至多 5,000 分的练习步长，接近评级线时取实际差距。理论分已经达成的谱面退出普通推分；剩余空间很小的谱面降权。单谱面 Rating 和账户 Rating 的接近程度只作次要依据。
- 推分优先已有成绩且目标较近的谱面。推 OP 要求理论有效空间已知且大于零，并参考邻近成绩距离各自理论 OP 的差距，降低同曲已有较高贡献、以及只有较大理论空间但缺少实绩支持的候选排名。综合兼顾适配、目标和 OP，抽取时也略微偏好不同定数和难度。
- FC、AJ、AJC 的参考分分别为 975,000、1,004,000、1,009,000，只用于缩小候选。FC/AJ 目标以连击标记判断；相近分数只是练习参考。AJC 目标为 1,010,000。
- 每轮按方向排序，从不超过 12 张、权重达到该轮第一名 60% 的谱面中按权重立方抽样。优先分配可选歌曲较少的方向。按 Bot、本人、会话、绑定代次和筛选条件记住上一次结果，最多 64 组，五分钟内降低重复歌曲的抽中概率。靠前候选有替代项时，尽量换掉至少一张，继续受同批歌曲去重限制。

## OP 字段

SEGA 的 LUMINOUS PLUS 更新说明写明通用分类和全曲 OP 总计改为按歌曲汇总，每首歌取最高 OP 的一张谱面。华立的国服 2026 公告确认了 LUMINOUS PLUS 更新基线，落雪国服 API 文档定义了单谱面 OP、账户总 OP 与配信过滤。国服公开资料未给出可用于预测每个目标分数的逐分 OP 细则。 [SEGA 更新说明](https://info-chunithm.sega.jp/7435/) · [国服更新公告](https://www.bilibili.com/opus/1106586598618693634) · [落雪国服 API](https://maimai.lxns.net/docs/api/chunithm)

| 字段 | 计算口径 |
| --- | --- |
| 当前谱面 OP | 直接读取本谱 `Score.over_power`。无记录时为未知。 |
| 当前歌曲 OP | 同曲符合条件的已记录普通谱面取最高 OP。整首未记录时为未知。 |
| 理论上限 | 本谱沿用项目的国服上限公式 `(定数 + 3) × 5`；歌曲上限取同曲各有效谱面的最大值。 |
| 本谱有效理论空间 | `max(0, 本谱理论上限 - 当前歌曲 OP)`，当前歌曲 OP 未知时此项亦未知。 |
| 实际提升 | 软件不输出增量预测。排名使用近邻实绩估计机会，图中的空间仅表示理论上界。 |

例如本谱当前为 80.00、上限 88.50，同曲 ULTIMA 当前为 88.00，则此谱对歌曲总贡献还能增加至多 0.50。上限 87.00 的另一张谱面即使打到理论值，也不会增加该歌曲的有效 OP。

## 离线复现

```powershell
python -X utf8 tools/preview_unibot_ui.py --catalog <本地公共曲库JSON> --jackets <本地公共曲绘目录>
```

脚本在临时 LocalStore 启动插件，使用实际在线命令调用的渲染函数。成绩、长曲名和昵称为合成演示，雅迪使用公共曲库中的 39 个原始 ID 排成五页。输出至 `.tools/preview-ui-final/`，包括 PNG、总览图和 `synthetic-results.json`。HDD 数字、评级和难度图件从本机已有素材读取。
