# 日服 HDD 更新日期机制

本轮在 `7580f8e` 的统一库上进行只读实验。分析器复用已有 XML、包和图片索引，另在两代原盘复核 86 份基础包 XML 的 SHA-256，直接读取 13 份原盘 `TimeTable.xml`，并解码两代机内告知 DDS 样本。扫描成功解析 SDBT 93,972 份、新框 SDHD 48,702 份索引 XML。19 份解析失败的原始路径保留在报告中。索引涵盖现有已导入的资源，原盘核对范围限于已列样本和已知数据目录。

## 物证含义

| HDD 字段或关系 | 实测含义 | 日期处理 |
| --- | --- | --- |
| `netOpenName` | 结构为 `id/str/data`。已索引的 94,268 条出现记录中 `data` 为空。SDBT 跨歌曲、称号、角色、技能、课程等对象，SDHD 跨歌曲、活动、地图区域、课程及图片。 | 保留原始三元组和盘范围。相同标签是组合线索，公开日期需要外部锚点及对象证据。 |
| SDHD 编号形式 | 145 个形如 `v2_XX G_S` 的盘内记录中，ID 百位区组按版本从 2000 到 2900，尾两位在 0–81。`00`、`05`、`10`、`15`、`20`、`25`、`30`、`40`、`45`、`50` 顺序各前进 100。 | 区组可帮助确认数据世代。标签组号与上线日无可验证换算，`v2_30 14_3` 对应 2633。旧框 `910` 在同盘曾配 `v1_45 05_1` 与 `v1_45 07_1`。 |
| `releaseDate`、`releaseTagName` | `releaseDate` 在 8,292 个 SDHD Music.xml 中出现，含普通歌曲的历史回填。`releaseTagName` 为内容归属，独立 ULTIMA 沿用原曲归属。 | 仅把字段原值作为曲目级候选。Aether Crest 曲目字段为 2025-02-25，达标地图在 2025-02-27 才开放。ERIS 的普通曲字段记录 2016-09-21，实测 ULTIMA 开放日为 2025-03-06。 |
| `data.conf`、选件编号、文件名时间 | 172 个 SDHD 基础与选件包都能用已有索引排列，73 个 SDBT 包中 44 个已有顺序。包内文件含预载、历史回填及不同路线。 | 可自动找到首次本地出现与内容修订所在包。构建日及下一周四误报很多。SUN PLUS A001 同时包含公告明确在 4 月 13 日和 5 月 11 日开放的内容。 |
| `Event`、`Course`、`Map`、`MapArea` | 可追踪曲号、区域、资源 Banner、结束活动 ID、时段引用。歌曲 `firstLock`、谱面位及 `enableUltima` 描述不同层级。13 份 `TimeTable` 样本有周内和小时条件。 | 关联开放路线、停配条件及曲谱归属。课程先行和通常开放保留独立日期，运营达标及玩家领取条件仍需服务侧证据。 |

`hdd_label` 在公告样本中有 5 个同键多日反例，另有 5 个日子对应多个三元组。LUMINOUS 的 `2400 / v2_20 00_0` 涉及 8 个已知日期。后续基础盘会把此前内容归入 `00_0`，失去原始上线分组。 [前轮官方公告与取证记录](SDHD_OFFICIAL_DATES.md)

## 独立验证

对新框 257 个可关联官方首配的对象按日期分组，每年每第三个日期整组留出。发现集为 61 日 181 个对象，留出集为 26 日 76 个对象。公告同日转发只用一条对象级样本。普通谱面与普通曲共享首配声明的样本只计普通曲，WE 父曲只计独立谱面一次。旧框另用已有 1,226 个带日期的档案对象复验，来源包含社区档案和先前已核官方证据，留出 53 日 359 个对象。

| 新框整日留出规则 | 覆盖 | 命中预测 |
| --- | ---: | ---: |
| 盘内完整开放标签 | 0 / 76 | 无预测 |
| 选件包，或选件包加开放标签 | 5 / 76 | 0 / 5 |
| 选件包、标签和谱面类别 | 10 / 76 | 0 / 10 |
| 原始 `releaseDate`，全部类型 | 18 / 76 | 12 / 18 |
| 原始 `releaseDate`，普通歌 | 6 / 48 | 6 / 6 |
| 原始 `releaseDate`，ULTIMA | 12 / 23 | 6 / 12 |
| 原始 `releaseDate`，WE | 0 / 5 | 无预测 |
| 构建日 | 51 / 76 | 0 / 51 |
| 构建日后的第一个周四 | 51 / 76 | 1 / 51 |

整日留出检验日期查表的弃权与误报。训练表只存已见日期，对一个完全未见日期的正确命中依赖 HDD 直接日期或其他独立证据。普通曲原值在整个样本的 60 个可用值中有 59 个匹配，Aether Crest 是明确反例。6 个命中不足以验证其他版本、待确认曲目或地图和服务器条件。

另做同日锚定验证。每个留出日公开一个独立对象，去除该对象及它的同曲谱面，评价其余对象。新框包号命中 **41/41**，覆盖 **41/49**，其中普通曲 23/31、ULTIMA 13/13、WE 5/5。完整标签命中 33/33，覆盖 33/49。包加标签和类型命中 27/27。旧框包加完整标签命中 277/277，覆盖 277/306。样本按对象计，且同一日可能贡献多个对象。完整档案已观察到多日冲突，因此这些规则只用于生成待审候选，即使当前只有一个日期也保持候选状态。

## 机内告知图

现有索引含 2,640 条活动到告知图引用、966 条活动到 Banner 引用和 846 条 Banner 定义。53 个已归档网页或 X 图像哈希与 HDD 图片字节哈希零重合。DDS 与网页 PNG/JPEG 存储格式不同，字节比对只检验文件同一性。直接解码的旧框 PLUS 新曲图可看见曲名，抽查两张没有印日。NEW 机内 `CHU_info_music_new0212.dds` 的图首印有 `11月4日(木) 楽曲追加`，图卡列出曲名。其 `Event.xml` 写明 2021 年 11 月首轮开服。参考官方开服日确认年份及公告适用范围。

在同一原盘图里确认 GO! GO! MANIAC、名前のない怪物、うまぴょい伝説。重建通过 `Event.xml → DDS 路径与 SHA-256 → 原盘同包曲号和难度` 核对 3 首普通曲及 12 张同包普通谱面。本轮自动日期规则入库量为零。人工核读的 DDS 证据由构建器可重复核验入库。ULTIMA、WE、定数和记谱修订本轮没有新增精确日期。已有 2,164 次定数、1,307 次显示等级、170 次记谱变化仍保留所见更新包，原来已定日的 4 次记谱修订继续有时间证据。 [NEW 官方开服告知](https://info-chunithm.sega.jp/1151/)

后续盘可复用只读扫描、标签分组、反例检测、候选日期导出与图库引用校验。可以通过带年份、明确开放行为与曲谱身份的图证入库，或在取得可独立验证的运营排期后校准候选。图片印刷日可能是活动窗口、通常开放或公告宣传，需结合事件类型和曲谱见证。

## 运行

```powershell
python -X utf8 tools/audit_hdd_date_mechanism.py `
  .tools/jp-hdd/official-final/catalog.sqlite `
  --output .tools/jp-hdd/date-mechanism `
  --old-root 'E:\SDBT 11 in 1' --new-root 'E:\SDHD'
```

`mechanism.json` 保留样本、字段计数、全部错误预测、包顺序、资源引用和修订统计。`gap-candidates.csv` 保留曲目级原始日期及已知批次锚点，它们可用于后续核查。统一库用前轮命令及已更新的公告清单重建，输出目录为 `.tools/jp-hdd/date-mechanism/rebuilt`。`coverage.json` 和 `verification.json` 记录本轮对照与快照验收。
